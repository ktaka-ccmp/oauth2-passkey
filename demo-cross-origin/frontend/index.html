Cross-Origin Same-Site Demo

Pattern 2: Auth Server + Separate Resource API

Architecture: This demo shows how a separate Resource API can validate session cookies issued by the Auth Server. The cookie's Domain=.example.local allows sharing across subdomains.

Architecture

Auth Server (auth.example.local:3000) Resource API (api.example.local:3001) ├── Frontend (this page) ├── /api/info (public) ├── /o2p/passkey/* (authentication) ├── /api/protected (requires auth) └── Issues Cookie: Domain=.example.local └── Validates same Cookie (Cross-Origin)
