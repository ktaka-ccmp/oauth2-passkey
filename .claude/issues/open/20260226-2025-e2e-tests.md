## Description

Add browser-level end-to-end tests that exercise the full authentication flow including JavaScript execution, DOM interaction, and real browser behavior.

### Current Test Coverage

- **Unit tests**: Comprehensive coverage of individual modules
- **Integration tests**: 29 HTTP-level tests using mock OIDC provider and direct API calls
- **Security tests**: 19 consolidated security scenario tests

### Gap

No tests exercise the actual browser UI -- JavaScript execution, WebAuthn API interaction, popup window management, form submissions, etc. These flows are currently only tested manually.

### Considerations

- WebAuthn/Passkey requires browser-level testing (virtual authenticator)
- Chrome DevTools Protocol supports virtual authenticator for testing
- Playwright or similar tool can automate browser interactions
- CI integration requires headless browser support
- Test infrastructure complexity is significant
