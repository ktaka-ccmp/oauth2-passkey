## Description

Release v0.3.0 to crates.io. This release includes major new features (login history, passkey promotion, demo mode, admin force logout, CSS themes, feature flags), multiple breaking changes (env var/route renames, default value changes), and important bug fixes (JWKS deadlock, SQLite in-memory pool eviction).

Current workspace version is `0.2.1-dev`. The scope of changes far exceeds a patch release, with 4 breaking changes warranting a minor version bump under semver 0.x conventions.
